Qué es esto
Esto ya es la Fase 2: la estructura y el diseño son los mismos que validaste en la vista previa, pero ahora los cambios (editar una tarea, marcar % completado, crear un tablero nuevo, añadir un miembro) se guardan de verdad en una base de datos — todo el que abra este enlace ve lo mismo que tú, en tiempo real.
Lo que viene en la Fase 3: sincronización con Google Calendar y los correos automáticos (tareas atrasadas, resumen para caps/chief, dashboard semanal, aviso de nueva tarea). Esto necesita que crees un proyecto en Google Cloud con la API de Calendar y Gmail habilitadas — te paso los pasos exactos cuando lleguemos ahí.
Prueba también los botones de Miembros y Configurar desde cero, junto al selector de "Cuenta simulada" debajo de las pestañas, y el botón + tarea dentro de cada apartado: todo lo que hagas ahí queda guardado.
Configurar un Gantt desde cero
Así sería el primer paso si entraras a esta web sin ningún Gantt todavía: dices de qué departamento eres, y luego creas los subapartados de ese departamento (como GENERAL / M&I / ACCU / REFRI) — cada uno se convierte en una pestaña. Dentro de cada subapartado puedes crear a su vez otros apartados (por ejemplo, dentro de M&I: "Inverters", "Testbench"...). Se crea ya en la base de datos: al terminar, solo verás los Gantt de tu departamento.
Directorio de miembros
Nombre, correo y departamento de cada persona. Se guarda en la base de datos propia de este proyecto — cada cambio que hagas aquí (editar un campo, añadir o quitar a alguien) queda para todo el equipo.
